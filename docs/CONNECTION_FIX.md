# 生成不可とメール表示の修正

通常のAPKビルドには `example.workers.dev` の接続先が入り、端末内の設定チェックで生成が無効化されていました。
成功したCloud AIデプロイ（Actions run 39910596913）のログで公開済みURLを確認し、既定の接続先に指定しました。
`https://liefantidia2-ai-router.light06120602.workers.dev/generate-recipe`

- Gradle property、環境変数、local.propertiesの順で上書き可能。空値は無視します。
- すべてのビルドでHTTPS、ホスト、パス、認証情報・クエリ・フラグメントの不在を検証し、サンプルURLは拒否します。
- CIに有効な接続先がAPKに埋め込まれていることを確認する回帰テストを追加しました。
- 接続先のhealth応答と未認証リクエストの401応答を確認済み。
- アプリと同じUser-Agentで、Firebase匿名認証→実際のWorkerへの生成要求→HTTP 200と238文字のレシピ応答を確認。一時テストアカウントも削除済み。端末上のUI操作とは別の結合確認です。
- メールは設定画面で `li****12@gmail.com` のように表示します。1〜4文字の短いローカル部も全文を表示しません。
- ログイン済みでは隠れているメール・パスワード入力欄も消去します。
- 通信失敗時は前のレシピを残したまま、エラーと再試行の案内を画面上に表示します。
- 認証トークンを付けたリクエストの意図しない転送を防ぐため、HTTPリダイレクトの自動追従を無効化しました。
